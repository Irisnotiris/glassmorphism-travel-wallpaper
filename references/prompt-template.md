# 主提示词模板（Master Prompt）— 手机锁屏壁纸版

以下模板作为 `image_edit` 的 `prompt` 全文使用。占位符替换规则见 `SKILL.md`。所有画内文字必须用中文引号「“ ”」标注。

**文案动态推断**：`{{DISTANCE}}`、`{{PLACE_TITLE}}`、`{{SUBTITLE}}`、`{{WEATHER_LINE1}}`、`{{WEATHER_LINE2}}` 不使用固定值，必须根据上传图片的场景、地点、氛围自动推断匹配的英文文案。例如图片是雪山则推断山地相关地点与寒冷天气，图片是海滩则推断海滨地点与海风天气。全部使用英文。

---

设计一张 9:19.5 超竖版手机锁屏壁纸，高级玻璃拟态旅行信息卡风格。

**构图**：玻璃卡片小巧紧凑、高度较短，位于画面下半部分、位置靠下；画面上半部分大面积干净留白，只保留虚化背景，给锁屏大字号时间留出充足空间；整体上下呼吸感舒适。

**全屏背景**：背景必须是上传参考图的直接虚化版本——严格保留原图的构图、主体位置、色彩关系和场景内容，只做轻微虚化（高斯模糊）、降低饱和度、叠加柔和雾感，绝对不能重新生成、替换或改变背景中的任何景物。让整体有安静、通透、电影感的氛围。顶部区域背景尤其干净、低细节。

**中央悬浮卡片**：画面下半部分放置一张小巧紧凑的悬浮式圆角 UI 卡片，必须呈现非常真实、细腻的 frosted glass 毛玻璃质感：
- 半透明雾面玻璃，背景透过卡片后产生柔和模糊；
- 卡片边缘有非常细的白色高光描边，边缘略微发亮，像真实玻璃的厚度；
- 卡片内部有轻微折射感；
- 玻璃表面有极淡的光斑、柔和反光和空气感；
- 阴影很轻，但能看出卡片悬浮在背景上；
- 整体不要像塑料，不要像灰色半透明遮罩，要像真实的磨砂玻璃；
- 质感参考：Apple Vision Pro / iOS glass UI / 高级相机镜片反射 / 雾面亚克力。

卡片整体为大圆角矩形，颜色以雾白、浅灰、半透明蓝灰为主，透明度适中，既能看见背景，又不能影响信息可读性。

**卡片内部结构**（从上到下）：

1. 顶部是一个横向圆角搜索框：左侧搜索图标，文字为 “Search place...”；右侧是一个独立圆形 “+” 按钮。搜索框和按钮也需要是毛玻璃质感，有细腻阴影和高光。
2. 中间是一张大尺寸圆角图片预览图：内容从上传图片中裁切出最有代表性的区域。预览图边角圆润，带轻微阴影，像嵌入在玻璃卡片中的照片窗口。
3. 预览图左下角叠加距离文字：小号 “{{DISTANCE}}”，直接浮在照片上。
4. 预览图下方的地点信息：大号地点标题 “{{PLACE_TITLE}}”，小号副标题 “{{SUBTITLE}}”，两行纵向排列。
5. 预览图右下角放一个半透明圆角按钮，文字为 “Directions”，只此一个，卡片其他位置不得再出现 Directions。
6. 底部是简洁天气信息区，两行小字，所有底部元素都要轻、细、干净，有 Apple UI 的克制感：第一行 “{{WEATHER_LINE1}}”，第二行 “{{WEATHER_LINE2}}”。

**文字唯一性铁律**：整个画面中 “Search place...”、“+”、“{{DISTANCE}}”、“{{PLACE_TITLE}}”、“{{SUBTITLE}}”、“Directions”、“{{WEATHER_LINE1}}”、“{{WEATHER_LINE2}}” 每一段都只出现一次，不得重复渲染，也不得添加任何其他文字内容（包括状态栏、时间、电池、信号图标等）。

**整体风格**：高级、通透、安静、干净、低饱和、真实摄影感、现代 iOS 产品界面感。重点不是做复杂 UI，而是做出真实玻璃层叠在照片上的质感。
