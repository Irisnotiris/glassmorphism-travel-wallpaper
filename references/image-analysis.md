# 图片分析指南

阶段1使用。仔细观察上传图片，从以下维度提取线索，用于后续地点推测和文案生成。

## 观察维度

### 1. 场景类型
判断图片属于哪一类：
- **海滩/海岸**：海水、沙滩、礁石、海岸线
- **山地/高原**：山峰、雪山、草甸、云海
- **城市/都市**：高楼、街道、天际线、桥梁
- **古镇/村落**：老建筑、石板路、民居
- **森林/自然**：树木、溪流、瀑布、植被
- **沙漠/干旱**：沙丘、仙人掌、戈壁
- **湖泊/河流**：水面、倒影、湿地
- **其他**：明确标注

### 2. 地理特征
- 有无海洋？海岸线是悬崖还是沙滩？
- 有无山脉？是雪山还是岩石山？
- 有无岛屿、湖泊、河流？
- 地形是平坦还是起伏？

### 3. 建筑风格
- **地中海风格**：白墙、彩色房屋、红瓦、圆顶教堂
- **阿尔卑斯风格**：木屋、陡坡屋顶、石墙
- **东亚传统**：飞檐、寺庙、竹林、和服/汉服元素
- **伊斯兰风格**：穹顶、尖塔、马赛克
- **现代都市**：玻璃幕墙、摩天楼
- **无明显建筑**：纯自然风光

### 4. 标志性元素
寻找能指向具体地点的独特元素：
- 特定建筑（比萨斜塔、埃菲尔铁塔、圣托里尼蓝顶教堂）
- 特定植被（棕榈树→热带/地中海，松树→地中海/山地，仙人掌→沙漠）
- 特定地貌（石林、火山、冰川）
- 文字/招牌（如果清晰可辨，直接提取地点线索）

### 5. 主色调与氛围
- 冷色调（蓝、青、灰）→ 冷静、宁静、清晨/傍晚
- 暖色调（橙、黄、金）→ 温暖、日落、阳光
- 高饱和 → 明亮、热烈
- 低饱和 → 安静、电影感、雾感
- 明亮/阴暗、晴天/阴天/雾天

### 6. 主体位置
- 画面主体（建筑/山峰/人物）在哪个区域？
- 这决定预览窗应该裁切哪个区域最有代表性。

## 输出格式

分析完成后，用以下格式记录（供后续阶段使用）：

```
场景类型：海滩/山地/城市/...
地理特征：有海洋，悬崖海岸线，远处有山
建筑风格：地中海白墙彩色房屋，有圆顶教堂
标志性元素：圆顶教堂、彩色房屋、悬崖海岸
主色调氛围：暖色调，阳光明媚，金色光线
主体位置：画面中下部的悬崖小镇
一句话描述：{{IMAGE_DESCRIPTION}}
```

## 注意事项

- 不要凭印象猜测地点，地点推测留到阶段2通过联网搜索完成
- 如果图片中有清晰的文字/招牌，记录下来，这是最强的地点线索
- 如果图片是纯自然风景（无建筑），地点推测可能只能到区域级别，文案用泛化描述
